Pilot Flashcard Support

Need help with Pilot Flashcard? You can report a problem, ask a question, or request support through the project's GitHub Issues page.

Open a Support Request on GitHub

When Reporting a Problem

Please include a short description of the issue, the iPhone or iPad model you are using, your iOS version, and any steps that help reproduce the problem. Please do not post sensitive or private information.

Purchase Issues

If paid content does not unlock after purchase, first try reopening the app and using any available restore-purchases option. For billing or App Store payment issues, contact Apple Support.
